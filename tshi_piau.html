客製化鼠標製作平台

把喜歡的角色做成 Windows ANI／CUR 游標，或匯出 Chrome 用靜態 PNG

① 上傳圖片與設計角色

JPG／圖片背景處理

本機移除接近純色且連到圖片邊緣的背景。淺色或單色背景較容易去除；相似度調太高可能會吃到角色邊緣。

文字、連結等游標可以不選圖片。上傳角色圖時，游標會畫在角色下層；按上方「移除圖片」即可改做純游標。拖曳預覽或使用位置滑桿調整點擊熱點。

角色動態效果

眨眼是簡單的預設動畫，可自行開關；預覽會循環播放，匯出的 ANI 會帶入所選效果。

② 選擇用途、預覽並下載

一般選擇使用所選游標造型；拖曳預覽圖示即可移動最前端的點擊熱點。

箭頭配色

自動配色會擷取圖片主色調成淺色箭頭與較深外框；也可用色票自行調整。

箭頭／游標熱點位置 可拖曳預覽圖示

可分別選「一般選擇」與「連結選擇」下載 PNG，再放進 Chrome 外掛的 cursor／pointer 圖片欄位。PNG 不含 Windows CUR 的熱點資料，點擊位置依外掛本身設定。

可上傳角色圖片，也可略過圖片直接製作純游標。
③ 如何使用？
  1. 可上傳角色圖片，也可略過或移除圖片；JPG 可嘗試自動去背，再選擇游標用途。
  2. 調整角色大小、游標造型和熱點；眨眼效果可自行開啟或關閉。
  3. 下載所選用途的 ANI／CUR／透明 PNG，或一次下載含四種用途及兩種格式的 ZIP。
  4. Windows：設定 → 藍牙與裝置 → 滑鼠 → 其他滑鼠設定 → 指標，選取對應游標檔。

你的圖片、預覽畫面及產生的 ANI／CUR／PNG／ZIP 都在這個瀏覽器分頁本機處理，不會傳到網站或伺服器。
